### S1. 信息熵、条件熵、互信息是什么关系？KL 散度和交叉熵是什么关系？
- 来源：05 信息论（建议落位 ai-ml）
- 核心素材：
  - 自信息 h(A) = −log₂p(A)：**概率越小的事件信息量越大**（国足夺冠 1:1000 ≈ 10 bit，国乒 1:2 ≈ 1 bit）；信息熵 H(X) 是自信息在概率空间上的期望，**均匀分布时最大 log₂n**——熵是"系统内在混乱程度"。
  - 条件熵 H(Y|X) 的直觉：**先按 X 分类、算每类内的熵、再按 X 的分布求期望**——座位随机（熵大）vs 加了"男左女右"限制后每侧内部仍随机但整体更简单，分类带来了不确定性下降。
  - **互信息 I(X;Y) = H(Y) − H(Y|X)：通信领域叫互信息、机器学习叫信息增益，本质是同一个量**——特征 X 消除的关于 Y 的不确定性；这是"信息论支撑决策树"的桥。
  - KL 散度的编码论解释：用按 Q 设计的最优编码去编码真实分布为 P 的信源，**平均每符号多花的比特数**；性质：**非负（相同才为 0）+ 非对称（不是距离）**；D(P||Q) 最小化要求 Q 在 P≠0 处≠0（zero-avoiding），D(Q||P) 反之（zero-forcing）——两个方向近似行为不同。
  - **交叉熵 = H(P) + KL(P||Q)**：P（真实标签分布）固定时，最小化交叉熵 ⟺ 最小化 KL ⟺ 最大似然——一句话把"分类损失为什么是交叉熵"钉死（衔接 ai-ml-lr 的 MSE 对比）。
  - 最大熵原理：约束满足的前提下选**不确定性最大**的分布——不引入多余假设、预测风险最小（"别把鸡蛋放一个篮子"）；最大熵模型 = 特征函数约束 + 拉格朗日乘子的凸优化问题，解存在且唯一。
- 建议追问：① 为什么损失函数里用交叉熵而不是直接用 KL？（差一个常数 H(P)，梯度相同）→ ② 信息增益为什么天然偏好取值多的特征？信息增益比怎么修？（衔接决策树题）→ ③ 前向 KL 和反向 KL 的行为差异在哪个生成模型里体现最明显？
- 建议难度：intermediate

### S2. 贝叶斯网络和马尔可夫随机场有什么区别？"条件独立性"在图上怎么判断？
- 来源：33 概率图模型（建议落位 ai-ml）
- 核心素材：
  - 概率图模型 = 概率论 + 图论，用图表达随机变量的条件依赖；**贝叶斯网络 = 有向无环图**，把联合分布分解为条件概率因子乘积：p(A,B,C,D,E) = p(A)·p(B|A)·p(C|B,A)·p(D|B)·p(E|C)——朴素贝叶斯是"属性条件独立"的退化特例，**把属性间依赖纳入后就是通用贝叶斯网络**。
  - **参数节省的量化账**：8 个二值变量全联合要存 2⁸=256 个概率；若每个变量至多 2 个父节点，只需 8×2²=32 个——变量上千时"每个节点只有少量父节点"的优势是指数级的。
  - 三种连接的 d-分离直觉（面试核心陷阱在第三种）：**顺连** X→Z→Y、**分连** X←Z→Y（一因多果）——Z 已知时 X⊥Y（水闸关上）；**汇连** X→Z←Y（多因一果）——**Z 未知时 X⊥Y，Z 被观察反而打通信息通路**（解释消除效应：知道肇事者后，"刹车失灵"和"路滑"两个独立假设变得相关）。
  - 马尔可夫随机场 = **无向图**：不含因果关系、但解除环路限制（能表示循环依赖）；联合分布 = 各**团**的势函数乘积 ÷ 配分函数 Z——势函数乘积不为 1，必须归一化。
  - 建模两步：拓扑结构（领域知识）+ 条件概率表（EM 等方法训练）；用途双向：自底向上 = 由果溯因的诊断（医生看症状），自顶向下 = 由因得果的生成模型。
  - 收束框架："**表示（怎么建模）—推断（怎么算概率）—学习（模型对不对）**"三步是整个概率图模型的组织骨架。
- 建议追问：① 汇连结构里为什么观察到 Z 反而制造了依赖？举一个诊断实例 → ② MRF 为什么需要配分函数、算不动怎么办（近似推断的动机）→ ③ HMM 对应什么样的贝叶斯网络？（隐变量链 + 前向算法 = 按拓扑序边缘化，衔接 em-gmm 题 HMM 追问）
- 建议难度：intermediate

### S3. RBF 网络和 BP 网络有什么本质区别？它和 SVM 的高斯核是什么关系？
- 来源：19 径向基函数神经网络 + 12 支持向量机（建议落位 ai-ml）
- 核心素材：
  - **全局逼近 vs 局部逼近**：MLP 的每个权重对所有输出同等影响（牵一发而动全身，收敛慢）；RBF 神经元只对**中心附近**的输入响应——生理学依据是"感受野"（星光移动激活的是视觉神经的不同部分）。
  - 结构：三层；输入层到隐层**直连（权重为 1）**，隐层用高斯径向基函数 ρ(x)=exp(−‖x−wᵢ‖²/2σ²)，**区分各隐元的只是中心向量 wᵢ**（带宽共享）；输出层是普通线性组合。
  - **与核技巧的同构**：隐层把低维线性不可分数据映射到（大概率）线性可分的高维空间——和 SVM 的思想一模一样，高斯核函数形式一模一样；但反例说明"非线性映射不必升维"：对 XOR 四点，只用两个高斯函数 φ₁,₂=exp(−‖x−u₁,₂‖²)（u=[0,0],[1,1]）就把 (0,1)、(1,0) 映到同一点 (0.368, 0.368)，**二维内直接变线性可分**——"杀鸡不必宰牛刀"。
  - 多变量插值视角：RBF 学的是一张高维超曲面——每个训练样本放一个高斯、全空间求和成曲面，新样本的取值由**近邻样本贡献为主**（局部性再次体现）。
  - **两阶段训练（考点）**：隐层用 **K-Means 聚类**定中心（K = 隐元数；带宽经验公式 σ = d_max/√(2K)），输出层用**递归最小二乘**做线性拟合；最后可用 BP 对整个网络微调（分步优化各自最优 ≠ 整体最优）。
  - 两者都能实现万能逼近——差异不在能力在**归纳偏置**（局部性 vs 全局性）。
- 建议追问：① RBF 的输出层为什么可以一步最小二乘解、不需要 BP？（隐层固定后是线性模型）→ ② 高斯核 SVM 和 RBF 网络哪个更该说"学中心"？（SVM 中心=支持向量、对偶求解；RBF 中心=K-Means 学出来）→ ③ K 取太大/太小各发生什么？
- 建议难度：intermediate

### S4. 自编码器到底在学什么？欠完备/稀疏/去噪/变分各解决什么问题？
- 来源：26 自编码器 + 28 深度信念网络（建议落位 ai-dl）
- 核心素材：
  - 目标不是预测输出而是**重构输入**（编码 φ + 解码 ψ，min‖X − ψ(φ(X))‖²），无监督地学"数据的重新表达"；信息论视角：编码 = 对输入信源的**有损压缩**。
  - **欠完备**（隐层维度 < 输入）：线性神经元 + MSE 准则下**等价于 PCA**（k 个隐元保留前 k 个主成分）；非线性激活则能捕捉分布中更复杂的特征（高斯误差下 MSE 等价最大似然）。
  - **过完备悖论（好题眼）**：隐层比输入宽时本可学恒等映射偷懒——但 SGD + 早停 ≈ L2 正则使"隐层小权重 + 输出层大权重"的完美重构方案难以实现，网络**只能利用训练集的统计规律重新编码**——瓶颈与正则化至少居其一，表示学习才成立。
  - 变体谱系（每个变体 = 一种"好表示"的答案）：**稀疏 AE**（KL 散度正则控制激活率，如只激活 1%）；**去噪 AE**（从损坏样本 X̃ 恢复 X——不能靠复制、必须学稳健特征，是 MAE/对比学习的先声）；**收缩 AE**（雅可比矩阵 F 范数正则，抑制流形上的微小扰动）；**变分 AE**（隐变量参数化为正态分布、KL 做度量，学到分布 → 能生成）。
  - **栈式 AE 与预训练范式**：多个浅层 AE 逐层贪心预训练（上层输入=下层输出）+ 反向传播整体微调；分类时丢掉解码器、隐层输出接 softmax。RBM/深度信念网络（对比散度训练）走的是同一条"无监督逐层预训练 + 有监督微调"路线——2006 年这是深网唯一可行的训练法。
  - 历史闭环：逐层预训练后来被 ReLU/BN/良好初始化取代（梯度弥散的真凶是激活函数不是 BP），但"预训练+微调"在 LLM 时代以海量数据的形式王者归来（衔接 ai-llm-pretrain-sft-rlhf）。
- 建议追问：① 过完备自编码器为什么不学恒等映射？正则化在其中的角色 → ② AE、VAE、GAN 生成机制的差异（隐式采样 vs 显式分布）→ ③ 去噪 AE 和扩散模型"加噪-去噪"的思想连续性。
- 建议难度：intermediate

### S5. 迁移学习在解决什么问题？"迁移什么、能不能迁移、如何迁移"分别指什么？
- 来源：35 迁移学习（建议落位 ai-ml）
- 核心素材：
  - 打破经典 ML 的两个前提：**训练/测试同特征空间同分布 + 有足量高质量标注**——时间漂移导致分布变化、标注又贵又受知识产权约束，没有数据再好的深度学习都是无源之水。
  - 按域/任务关系分三类：**归纳迁移**（目标任务不同，目标域可少量标注）、**直推式迁移**（域不同、任务相同，如 A 领域标注 → B 领域同任务）、**无监督迁移**（两边都无标注）。
  - 四种方法谱系（"如何迁移"）：**基于样本**（TrAdaBoost 迭代调源域样本权重——鼓励"好"数据、抑制"坏"数据；直推式用重要性采样/核均值匹配/KL 最小化）；**基于特征**（把两域映射到公共低维空间，或选共有特征）；**基于模型**（共享参数/先验——预训练+微调就是它的大规模形态）；**基于关系**（社交网络/物理网络的关系结构迁移，不要求 i.i.d.）。
  - **能不能迁移 = 负迁移防线**：源域目标域不相关时硬迁移有害（骑自行车的技巧骑三轮车会翻车）——迁移前要评估域相关性。
  - 与多任务学习的分界（易混考点）：多任务学习**同时提升**源任务与目标任务；迁移学习**只用源域帮目标域**（工程上给目标域损失更大权重）。
  - 现代印证：Siri 声学模型跨带宽/跨语言初始化（宽带预训练 → 蓝牙语音、英语预训练 → 汉语，特征变换的泛化性不依赖具体语言）= 基于模型迁移的工业实例；元学习 = "对学习方法的学习"，归纳偏差与问题匹配才有好效果。
- 建议追问：① 预训练+微调属于哪一类哪种方法？（模型/参数迁移）LoRA 呢？→ ② 怎么在训练早期发现负迁移？（目标域验证集表现 vs 不迁移 baseline）→ ③ 直推式和归纳式的核心差别为什么是"目标域有没有标注"。
- 建议难度：intermediate

### S6. 机器翻译从规则到神经经历了哪几代？"漏译和译文偏短"是怎么被工程修正的？
- 来源：40 机器翻译 + 32 长短期记忆网络（建议落位 ai-dl）
- 核心素材：
  - **三代演进**：逐词对应（词典匹配——一词多义 + 语境表达差异，日常语言里是灾难）→ 基于规则（乔姆斯基《句法结构》：语言的基本元素是句子不是词，有限规则生成无限句子——但规则维护不动，"我勒个去"翻不动）→ 基于统计/实例（海量平行语料）→ **神经机器翻译（GNMT，2016）**：整句为翻译单元、端到端。
  - GNMT 结构（注意力诞生于翻译的经典叙事）：编码器/解码器各 **8 层 LSTM + 残差连接**，注意力模块连接编码器最底层与解码器最顶层——解码时对不同输入部分动态加权（相比旧短语系统翻译误差降 60%）。
  - **beam search 的两个工程修正（本题题眼）**：**覆盖率惩罚**——保证输入每个部分都有输出对应，防漏译；**长度正则化**——否则解码器天然偏好短序列。这两个修正说明：序列生成的目标函数有系统性偏差，要显式补偿（衔接 ai-llm-decoding 的 beam search 残存阵地）。
  - **零知识翻译（多语互译）**：输入前加目标语言标志 + 共享词胞数据集，一套模型 103 种语言互译；未见语言对靠英语"桥接"——模型数从任意两两配对的 100²=10000 降到 100×2=200，代价是翻译时间翻倍、转译链可能偏离原意。
  - 洞见级收尾：转译过程中网络不是在记忆短语映射，而是对句子**语义重新编码**（谷歌称 interlingua"国际通用语"）——这是"翻译模型学出了语义空间"的最早证据之一。
- 建议追问：① 为什么逐词直译注定失败？（歧义 + 语序重排）→ ② 注意力解决了翻译的什么根本难题？（长句软对齐，替代固定长度向量瓶颈）→ ③ 零样本翻译的桥接在什么语言对上会翻车？（低资源 + 结构差异大）
- 建议难度：intermediate

### S7. 感知器为什么解决不了异或问题？加了隐藏层为什么就能解决？
- 来源：17 神经元与感知器 + 18 多层感知器 + 19 RBF（XOR 数值例）（建议落位 ai-dl）
- 核心素材：
  - 感知器 = 输入线性加权 + 阶跃传递函数的二分类器，按误差自适应调权；本质是**线性分类器**，决策边界是一条直线/超平面。
  - **XOR 四点 (0,0),(0,1),(1,0),(1,1) 对角同色——线性不可分**：不存在任何直线把两类分开，单层感知器数学上无解；这正是"一位青年才俊的意外死亡"（Rosenblatt 与感知器寒冬）的技术根源。
  - 解法一（主流）：加隐藏层成多层感知器——隐藏层把输入**非线性变换**到新的表示空间，再线性划分；误差经**反向传播**逐层回传调权；单隐藏层即可**万能逼近**任意连续函数。
  - 解法二（课程独有数值例，RBF 篇）：**不升维也能解决**——用两个高斯函数 φ₁,₂(x)=exp(−‖x−u₁,₂‖²) 把四点映为 (0.135,1)、(0.368,0.368)、(0.368,0.368)、(1,0.135)，中间两点重合后线性可分——"换表示"与"升维"是两条等价思路。
  - 与现有题的分工：ai-dl-activation 讲"无非线性则多层等价于一层"，本题把同一结论从**几何直觉（找不到分界线）**切入并给出具体映射数值例，构成手推型考题。
- 建议追问：① 两层网络手工设权重/偏置解 XOR（隐藏层 OR−AND 的经典构造）→ ② 为什么多个线性层叠加救不了 XOR？（复合仍是线性）→ ③ 万能逼近定理承诺了什么、没承诺什么？（没承诺宽度/数据量/可训练性）
- 建议难度：basic

### S8. 强化学习和监督学习的本质区别是什么？基于价值、基于策略、基于模型三类方法怎么分？
- 来源：27 深度强化学习（建议落位 ai-dl）
- 核心素材：
  - 本质区别：监督学习有明确标签，**强化学习的环境反馈只是"动作好坏"的评价性信号**（信息量少）；智能体必须在**探索未知与利用经验**之间平衡；训练数据是自己交互产生的、非 i.i.d.。
  - 马尔可夫决策过程四元组 (S, A, P, R)：状态集、动作集、状态转移概率、实时奖励；目标 = 最大化**累积**奖励。
  - **三类方法**：**基于价值**（学 Q 函数、间接得最优策略——Q-learning 是有限集搜索、无泛化，DQN 用网络参数化 Q）；**基于策略**（直接参数化策略做梯度上升，缺点是需要大量在线交互轨迹）；**基于模型**（学转移概率 p(r,s′|s,a) 指导决策——省真实交互，但概率误差沿长序列累积会南辕北辙）。
  - **DQN 两个关键机制（必背）**：**经验回放**——历史状态转移存起来随机重放，打破数据相关性 + 复用数据；**目标 Q 网络**——单独一个网络产生目标值、定期同步，避免"用自己追自己"的非平稳目标震荡。
  - actor-critic（UNREAL 实例）：行动者 = 策略网络、评论家 = 价值网络——"价值观指导行为、经验反哺价值观"；异步多环境采集 + 辅助任务（对同一份训练数据挖得更充分）。
  - 现代衔接：RLHF 的 PPO 就是策略梯度一脉（衔接 ai-llm-pretrain-sft-rlhf 的四模型/GRPO 追问），本题补足 RL 基础盘。
- 建议追问：① 经验回放为什么必须"随机重放"？（连续样本强相关 → 梯度估计有偏）→ ② 目标网络不冻结会发生什么？（追逐移动目标不收敛）→ ③ 价值法与策略法各自适用边界（离散小动作空间 vs 连续动作空间）。
- 建议难度：intermediate

### S9. GAN 的对抗训练是怎么运作的？最优判别器是什么？训练为什么难？
- 来源：31 生成式对抗网络（建议落位 ai-dl）
- 核心素材：
  - 零和博弈框架：生成器（从噪声模拟真实数据分布）vs 判别器（分辨真假）；训练目标 **min_G max_D**，整体是极大极小问题，用**交替迭代**优化——通常判别器更新多次、生成器更新一次。
  - **最优判别器有解析解：D\*(x) = p_data(x) / (p_data(x) + p_g(x))**——判别器本质上在估计两个分布密度的比值；当且仅当 p_g = p_data 时全局最优，此时 D 处处输出 0.5（真假不可分）。
  - 与传统生成模型的差异（好答点）：传统生成模型要先假设分布形式再估参数（人脸没有可写的先验分布）；GAN **摆脱分布形式假设**、不限制生成维度；且**判别器就是生成器的损失函数**——损失函数随训练自动演化，"自学习损失"是传统模型做不到的。
  - **训练难的根源**：要在高维连续参数空间达到纳什均衡，问题非凸 → 难收敛/欠拟合；谷歌对 200+ 变体的元研究结论"无证据表明哪个变体有实质改进"——理论缺失导致改进方向盲目（"炼金术"批评）。
  - 分工声明：ai-diffusion 题已讲"扩散为何取代 GAN"（稳定性/多样性），本题讲 GAN 自身机制，互为前后手。
- 建议追问：① 判别器太强/太弱分别发生什么？（太强梯度归零学不动，太弱学不到真实分布）→ ② 模式坍塌在 minmax 框架下怎么理解？（生成器找到判别器分不出的一小片"安全区"即可得分）→ ③ GAN 与 VAE 的生成机制差异（隐式采样 vs 显式似然 + KL）。
- 建议难度：advanced

### S10. 任务型对话系统和开放域聊天机器人的技术路线有什么区别？
- 来源：39 对话系统 + 38 语音处理（建议落位 ai-dl）
- 核心素材：
  - 三代演进：**Eliza（1966，模式匹配 + 脚本**，五要素：关键词识别/最小语境判定/转化选择/回复生成/结束能力）→ **智能个人助理（Siri 类，目标导向**）→ **社交聊天机器人**（满足沟通/情感/归属的感性需求）。
  - **任务型 = 空位填充（slot filling）**：每个任务定义一组特征空位（订餐厅 = 位置/价格区间/菜式），限定轮次内填完即完成；架构对应 Siri 的"语言解释器 + 会话流控制器 + 任务控制器"——**可控、可评测，但每个任务人工定义空位、跨域无法复用**（订餐系统推不了电影）。
  - **端到端 = 记忆网络**：每句话存入记忆模块实现长期记忆，迭代读取历史 + 结合上下文生成回复；**无需人工定义槽位、通用性强**，代价是可控性与可评测性变差。
  - 在线互动学习（Facebook 路线）：反馈两种形态（显式数值反馈 vs 人类自然的文本反馈）；**主动提问三场景**——问题澄清 / 知识运用 / 知识获取；"何时提问"本身是**强化学习**问题（提问消耗人类耐心，要按提问成本学策略）——十万个为什么机器人必被弃用。
  - LLM 时代对照（收束加分）：LLM + function calling 把 slot filling 变成了结构化输出与工具调用，记忆网络的角色被上下文/检索取代——但"状态跟踪 + 可控性"仍是任务型对话的核心命题（衔接 ai-llm-agent 题）。
- 建议追问：① 任务型对话 pipeline 各环节职责怎么切？（理解 → 状态跟踪 → 策略 → 生成）→ ② 端到端为什么"通用但难控"？→ ③ 用 LLM 重构任务型对话，哪些老问题消失了、哪些新问题出现了？
- 建议难度：basic

### S11. 过参数化的深度网络为什么还能泛化？NTK（神经正切核）视角在讲什么？
- 来源：文章《深度学习为何泛化的那么好？秘密或许隐藏在内核机中》+《UC伯克利发现「没有免费午餐定理」加强版》（建议落位 ai-dl，advanced 理论题）
- 核心素材：
  - 传统统计学习预言：参数太多必过拟合（U 形曲线），但 VGG/现代 LLM 参数百万到千亿级泛化却极好——**过参数化悖论**是深度学习理论的核心悬案（衔接 ai-ml-model-evaluation 的 VC 维、ai-ml-bias-variance 的 U 形）。
  - **隐式正则化不是答案（实证反例）**：张志远等用被操纵的数据集证明 AlexNet 级网络**确实可以**记住随机标签（能过拟合），而同样的网络在真实数据上泛化很好——"训练机制隐式限制参数量"的解释被否掉，需要新理论。
  - **NTK 等价（Jacot et al., NeurIPS 2018）**：特定随机初始化 + 无限宽网络 + 梯度流（无穷小步长）下，网络在整个训练过程中**等价于一个固定不变的核做核回归**——核只依赖网络架构（深度/连接方式），不依赖训练数据；函数空间视角下损失面是简单碗状，**可证明梯度下降全局收敛**（参数空间证明不了的，换到核空间证出来了——"物理学家取极限简化问题"的方法论）。
  - 前史与延展：Neal（1994）证明单隐层无限宽网络初始化时等价高斯过程，2017 年推广到深度；Belkin 实证**核方法自身在无显式正则下也不过拟合且泛化好**——深度网络的谜和核方法的谜是同一个谜。
  - **伯克利 NTK 特征值理论（文章 2）**：NTK 特征值可准确预测网络学任意函数的 MSE 与一阶/二阶统计量；**谱偏置**——特征值大的"低频"模先被学习（网络天然偏好缓变函数）；**加强版没有免费午餐**：把每个网络看作 NTK 特征空间中的高维向量，**对某目标函数泛化变好，必然以对（近似）正交函数泛化变差为代价**——可学习性存在零和竞争，"归纳偏置守恒"；结论在宽度 20 的有限网络上也近似成立。
  - 边界与争议（答题必须有）：等价性前提是**无限宽 + 参数单步变化极小**，与实际训练（参数大幅移动）有差距；批评者指出理论假设目标函数已知——"它解释了理想化网络为什么好，还没有完全解释你的网络为什么好"。
- 建议追问：① 用"加强版没有免费午餐"解释为什么没有万能的预训练模型？→ ② NTK 等价的三个前提分别是什么？哪个在现实中最不成立？→ ③ 这套理论与 double descent 现象是什么关系？
- 建议难度：advanced

## 二、既有题增强素材（ai-ml / ai-dl 对应题）

### E1. 目标题目：ai-ml-tree-ensembles
- 追问素材：**"C4.5 的信息增益比具体怎么用？基尼系数为什么能替代熵？"**——C4.5 是两步筛选：先取信息增益**高于平均水平**的候选特征，再在其中选增益率最高者（直接用增益率会矫枉过正偏好少值特征）；基尼系数 1−Σpₖ² 与熵高度近似但**免去对数运算**，CART 用它且每次只做**二分**（{A₁}/{A₂,A₃} 等组合枚举找最优切分点）、可分类可回归；延伸：单变量决策树边界是轴平行的分段，**多变量决策树**（斜线边界）是补非线性能力的老方案。

### E2. 目标题目：ai-ml-svm
- 追问素材：**"函数间隔和几何间隔差在哪？SMO 是怎么解 SVM 的？"**——函数间隔未归一化、几何间隔 = 函数间隔/‖w‖；两类支持向量到超平面距离之和 2/‖w‖，最大化间隔 ⟺ min ½‖w‖²；SMO（序列最小最优化）把大 QP 每次分解成**只有两个变量**的子问题求解析解（选一个变量再配一个保证约束可行）；核函数家族补全：多项式 (XᵀY+c)^d、拉普拉斯 exp(−‖X−Y‖/σ)、Sigmoid tanh(βXᵀY+θ)；**正定核充要条件 = 任意样本集的核矩阵半正定**，每个核隐式定义一个再生核希尔伯特空间——"核函数选错 = 映射到不合适的特征空间"，是 SVM 实际调参的核心。

### E3. 目标题目：ai-ml-ensembling-diversity
- 追问素材：**"OOB 是怎么免验证集估计泛化误差的？随机森林的'两重随机'指什么？"**——放回抽样的极限未抽中比例 (1−1/n)ⁿ → 1/e ≈ **36.8%**，这些袋外样本天然构成验证集，包外估计是泛化误差的**无偏估计**；随机性一是行采样、二是**每个节点先随机抽 k 个属性子集再选最优划分**——若强属性恒被选中，所有树会同质化、行采样就白做了（特征扰动保多样性）；AdaBoost 的两个子问题可以口述：样本权重**升错降对**（错题重做）、组合权重与错误率挂钩（错得少权重大，权重和不必为 1），整体 = **加法模型 + 前向分步 + 指数损失**——和 GBDT 拟合负梯度是同一思想的两种推导。

### E4. 目标题目：ai-ml-overfitting-regularization
- 追问素材：**"为什么正则化通常只罚权重不罚偏置？早停和 L2 什么关系？"**——每个权重指定两个变量间的相互作用方式、拟合所需数据量大；**偏置只控制单个变量，不正则也不产生大方差，乱正则反而增加偏差**；早停是深度学习中应用最广的正则化（不改训练过程、不影响学习动态），**简单模型下与 L2 正则化数学等价**（泛化误差 U 形：验证集 n 轮不改善即停）；框架级补充：正则化五分类——数据（增强/Dropout）、架构（**参数共享**——CNN 权重共享本质就是正则化）、误差函数/正则项（权重衰减）、优化过程（初始化/更新规则/**早停**）；数据集增强只作用于输入层和隐藏层、不动输出层。

### E5. 目标题目：ai-ml-gradient-descent
- 追问素材：**"深度网络的损失面有什么病态结构？局部极小值为什么多到数不清？"**——**病态 Hessian**：条件数大时微小扰动引起解大幅波动，表现是**很小的更新步长也会增加代价函数**、学习异常缓慢（衔接 cs-math 条件数题）；局部极小值海量的根源是**隐藏神经元的交换对称性**——m 层每层 n 神经元有 (n!)^m 种等价排列，网络变体不可辨认 → 等价局部极小成灾；**Nesterov 加速 vs 标准动量**：先按动量把参数临时更新到 w+v、再在 w+v 处算梯度——"先看再走"，避免冲太猛、更稳；坐标下降 = 分而治之（固定其余变量逐个优化，适合凸目标 + L1 正则）。

### E6. 目标题目：ai-ml-generative-discriminative
- 追问素材：**"LR 和朴素贝叶斯在什么条件下等价？概率连乘会出什么工程问题？"**——在一定条件下 LR 与 NB 收敛到同一分类器（生成式与判别式殊途同归的经典案例：数据充足渐近时决策面一致，小数据时 NB 方差小、LR 上限更高）；NB 选后验最大类别在 0-1 损失下就是期望风险最小化（衔接 decision-theory 的最小错误率决策）；高维下属性条件概率连乘**下溢** → 工程上全部取对数（log 后验）——"对数是概率计算的呼吸方式"这类细节能证明真写过 NB。

### E7. 目标题目：ai-ml-kmeans
- 追问素材：**"聚类算法除了 KMeans/DBSCAN 还有哪几族？聚类效果为什么没有绝对客观的评价标准？"**——按成簇方式分四族：**层次聚类**（凝聚/分裂，产出树状图、按阈值切簇）、**原型聚类**（KMeans/K-Medoids）、**分布聚类**（GMM，软分配）、**密度聚类**（DBSCAN）——一句话版谱系 + 按数据形状选型的完整口径；评价侧：无监督任务**不存在绝对客观标准**，高维/非均衡数据下"评价聚类甚至比设计聚类更难"——所以工业答案永远是"内部指标（轮廓系数）+ 业务画像可解释性"双确认（强化现有题收尾）。

### E8. 目标题目：ai-ml-em-gmm
- 追问素材：**"GMM+HMM 落地在哪？维特比除了解码还用在哪？"**——经典语音识别 pipeline：预处理 → 特征提取（**MFCC**，频域降维提基波/声道信息）→ **GMM-HMM 声学模型**（HMM 解决特征序列到音素的对齐、EM 训练）→ 语言模型 → 字典解码；维特比在合成侧同样挑大梁：Siri 单元选择合成中搜索**目标成本**（与目标特征的差异）+ **拼接成本**（相邻单元声学差异）加权和最小的单元路径；Siri 的升级版用**深度混合密度网络（DNN+GMM 组合）**替代 HMM 预测单元损失——"EM 家族 + 动态规划"从课堂三硬币走到工业语音的完整证据链。

### E9. 目标题目：ai-dl-cnn
- 追问素材：**"卷积运算的数学本质是什么？DenseNet 和 ResNet 的连接方式差在哪？"**——把二维输入和核拉平后，**卷积就是内积：输出大小 = 输入块与核模板的相似度**——特征提取的本质是模板匹配，这解释了为什么多个核能同时提取不同特征；池化 = **聚合统计**：特征在图中的绝对位置不重要、与其他特征的相对位置才重要（找两只眼睛不需要知道精确坐标），max pooling 取"最明显的特征"，顺带获得小幅平移/旋转鲁棒；**DenseNet**：任意两层直连、每层输入 = 之前所有层输出的集合——特征跨层重用 + 损失直连每层（缓解梯度弥散）；代价是参数随层数**平方**增长 → 瓶颈层 + 每层只学极少特征，总参数反而比 ResNet 少约一半。

### E10. 目标题目：ai-dl-rnn-lstm
- 追问素材：**"循环 RNN 和递归 RNN 是什么关系？遗忘门是原版就有的吗？"**——RNN 缩写两义：循环网络在**时间**上共享权重，递归网络在**树结构**上共享权重（前者是后者的特例）；递归网络的杀手锏是消解词序列解不了的歧义——"两个大学的老师"必须靠语法解析树定位"两个"修饰谁，输出是语义向量（可算情感/句相似度）；但训练需人工标注解析树、费时费力 → 实际远不如循环网络流行（"性价比"口径很加分）；LSTM 补充细节：**最初版本只有输入门/输出门，遗忘门是后来的改进**；**peephole（门镜）连接**让三个门都能看到细胞状态当前值，提升对时间间隔"节奏"模式的识别。

### E11. 目标题目：ai-dl-backpropagation
- 追问素材：**"梯度消失的锅到底该谁背？逐层预训练是怎么兴起又退场的？"**——归因修正：梯度弥散的根源**不是 BP 算法本身，而是非线性激活函数的非理想性质**（sigmoid 饱和）——所以 ReLU/BN/初始化才能治本；2006 年 Hinton 的逐层无监督预训练（RBM/AE 贪心堆叠 + 微调）是深网唯一可行训练法（每层独立优化、不受连乘衰减困扰），后来**良好初始化被证明比预训练更高效**、预训练退场——但同一范式在 LLM 时代以"海量数据预训练+微调"回归：同一件事的死亡与重生，是答"表示学习演进史"的最佳素材（与 S4 呼应）。

### E12. 目标题目：ai-dl-embedding
- 追问素材：**"知识图谱的 embedding 是怎么做的？和 Word2Vec 什么渊源？"**——分布式知识表示（KG embedding）：把实体和关系嵌入连续向量空间，定义**打分函数**衡量三元组成立的可能性（头实体 + 关系 ≈ 尾实体的平移思想），优化问题学出低维向量；下游任务：**链接预测**（给实体对算所有候选关系的得分）、三元组分类（得分过阈值）、实体对齐（向量相似度）；与 Word2Vec 的收束句升级："学出好向量"从文本共现扩展到了**结构关系**——符号知识第一次变得可计算（衔接 ai-llm-graphrag 的向量 vs 图谱互补）。

### E13. 目标题目：ai-ml-dimensionality-reduction
- 追问素材：**"特征选择和特征提取（降维）是一回事吗？过滤/包裹/嵌入怎么选？"**——特征选择 = **从原始特征中选子集**（可解释、保留原语义），降维/特征提取 = 造新特征（PCA 的新属性不可解释），两条互补路线；三法谱系：**过滤法**（先按统计量筛：方差/卡方/互信息——快、与模型无关但可能选出"单独无用组合有用"的特征）、**包裹法**（子集 + 模型验证表现评估——最准但计算贵、易过拟合）、**嵌入法**（训练中顺带选：L1 稀疏、树的重要性——效率与准确折中，工程默认）；与维数灾难题衔接：样本预算紧张时"先特征选择再谈降维"。

### E14. 目标题目：ai-dl-attention
- 追问素材：**"注意力机制出生在哪里？"**——比 Transformer 早两年：GNMT（2016）的编码器-解码器 LSTM 间就插了注意力模块，让解码器在每步对源句不同部分动态加权——**注意力是为了解决翻译的"固定长度向量瓶颈/软对齐"而发明的**，Transformer 只是把它请上了主角位；这条"翻译 → 注意力 → Transformer → LLM"的演化线能把 rnn-lstm/attention/机器翻译（S6）三题串成体系叙事，比孤立背 QKV 高一个层级。

## 三、主动丢弃

- 数学基础模块：线性代数（01）/概率论（02）/数理统计（03）/最优化方法（04）/形式逻辑（06）+《直播回顾：机器学习必备的数学基础》——全部停留在概念科普层（"特征值描述变化的方向与速度"级别），无独立考察深度；纯数学归 cs-fundamentals 的 cs-math 领域（贝叶斯/期望/分布/LLN-CLT/估计/假设检验/线代几何/最小二乘/凸优化/多元正态-马氏距离/SVD/条件数均已覆盖）；最优化的线搜索/置信域/牛顿法细节由 cs-math 凸优化题 + ai-ml-gradient-descent 覆盖足够。
- 机器学习概论（07）/线性回归（08）/逻辑回归（10）主体——监督划分、最小二乘=高斯误差下 MLE、岭/LASSO、softmax 多分类等已被 ai-ml-supervised-vs-unsupervised、ai-ml-lr、ai-ml-overfitting-regularization 与 cs-math 最小二乘题覆盖，无增量（09 朴素贝叶斯的可用细节已提入 E6）。
- 神经网络的生理学背景（16）——神经科学科普（神经元/突触/特征逐级整合），无面试考察点。
- 自组织特征映射 SOM（20）——竞争学习经典但工程面试极少考；其"无监督拓扑映射/降维"职能已被 PCA/t-SNE 题覆盖。
- 模糊神经网络（21）——小众混合系统，输入输出皆为模糊集合，无深度、无考频。
- 集群智能与蚁群优化（34）——启发式优化专题（信息素正反馈、可扩展/并行/容错三特性），算法岗考频极低，"涌现"仅作谈资。
- 深度信念网络 / RBM / 对比散度（28）——单独立题考频低；其核心思想（逐层预训练+微调的历史地位、梯度弥散归因）已并入 S4 与 E11，不重复成题。
- 知识图谱的马尔可夫逻辑网/概率软逻辑/路径排序算法（36 大部）——统计关系学习学术专题，考频低；仅"分布式知识表示"部分转为 E12 增强。
- 开篇词（00）/各复习课（一键到达，纯链接页）/结课/结课测试/推荐阅读/课外谈/新书/拓展阅读参考书等元内容——无知识点。
- 语音处理（38）与计算机视觉（37）的 pipeline 叙述——应用层流水线（预处理/特征/模型）在 E8（语音）与 ai-dl-cnn/E9（视觉）中已按需吸收；"手工特征 vs 学习特征"的宏观叙事与现有题归纳偏置表述重叠，不单独成题。
