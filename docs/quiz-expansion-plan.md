## 核心思路

参考库最值钱的是**带答案的试卷与作业**，作为"真题种子"**改写**成面试题（口试题 + 要点 + 追问链），不照搬笔试原题。
每题过四步管道：

1. **收割**：按课程目录批量读 A 层 md（试卷/作业优先，课件定深度基准），产出候选种子
   （题干原句、出处、考点、建议方向/难度）。
2. **映射去重**：候选对照 `src/data/trackMeta.generated.ts` 的题干与 tags，三分类——新增 / 增强（给现有题补追问）/ 丢弃。
3. **生成落地**：每方向一批，agent 输入 = 种子 + 该方向现有 data 文件 + README 内容约定，人工 review 后合并。
4. **门禁**：`npm run gen:meta` → `npm test`（id 唯一/标题查重/要点非空/https/难度排序/README 统计一致性）→ `npm run verify` → 常规三步部署。

## 优化约定

- **来源可追溯**：真题改编题打 `tags: ['真题改编']`，不动 `types.ts`。
- **难度校准**：试卷题天然偏中高难度，每批保证 ≥30% basic。
- **跨方向分工**：沿用现有约定（epoll 双视角写法），相邻方向在正文互相注明分工。
- **分包体量**：cs-fundamentals 加两大领域后观察分包体积，超预期再考虑拆方向。

  原文公式残缺的一律不编造。

- **stats 同步**：加题后 README 与 index.html 的题量 / 追问统计由 `stats.test.ts` 锁定，须同步更新。
